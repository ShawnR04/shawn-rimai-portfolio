

# Shawn Rimai — Developer Portfolio

> A clean, responsive portfolio site designed to highlight my work in full-stack development, modern web applications, and UI design. Built using Next.js, TypeScript, and Tailwind CSS.

Built with Next.js, TypeScript, and Tailwind CSS, this portfolio provides a fast, accessible, and polished experience across desktop and mobile devices.

## Tech Stack

### Framework

* Next.js
* React

### Language

* TypeScript

### Styling

* Tailwind CSS

### Icons

* Lucide React

### Hosting

* Vercel

## Key Features

* Responsive design optimized for desktop, tablet, and mobile devices
* Mobile-friendly navigation drawer
* Scroll spy navigation with active section highlighting
* Dark and light theme support
* Smooth scrolling between portfolio sections
* Project showcase for full-stack applications and development work
* Modern, accessible user interface
* SEO-friendly page structure and metadata
* Optimized performance using Next.js features
* Clean and maintainable component architecture

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js 18 or later
* npm

### Clone the Repository

```bash
git clone https://github.com/ShawnR04/portfolio-website
```

### Navigate to the Project

```bash
cd portfolio-website
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## Available Scripts

### Development

```bash
npm run dev
```

Starts the application in development mode.

### Production Build

```bash
npm run build
```

Creates an optimized production build.

### Production Server

```bash
npm run start
```

Runs the production build locally.

### Linting

```bash
npm run lint
```

Runs the project's linting checks.

## Deployment

This project can be deployed using any platform that supports Next.js applications.

For the simplest deployment experience, Vercel is recommended.

```bash
npm run build
```

Ensure all environment variables and production configuration are properly configured before deployment.
